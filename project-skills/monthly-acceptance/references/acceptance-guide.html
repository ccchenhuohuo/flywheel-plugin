范围 + 关键结果 + 证据正常环节用一句有范围、有依据的话写在相应位置；不折叠、不隐藏，不用“其余正常”替代。

重要异常

结果 → 贡献 → 源数据同一处讲清影响、证据与反证、判断和核查/修复方向；可疑变化与已确认错数分开。

待核或未完成

缺口 + 原因 + 使用限制没有数据、没有执行、无需继续检查是不同状态。它们如何限制放行也要可见。

先确认被观察的市场

整体需求、渠道交易迁移和采集可见性可能同时变化。平台增长不直接代表行业增长；平台份额必须核对同国、同类目、同期间与指标分母。

趋势合理 ≠ 幅度已经被解释
