# 月度大盘数据验收

用 3–5 个结论点直接说明总体能否使用、重要问题、证据限制及下一步；每点有关键数值或明确范围，不凑数量。

## 范围与历史是否完整

说明国家、平台、商品粒度与历史窗口；到货、批次、约定范围及历史出现/缺失的检查各有着落。正常一句话，疑点说明影响并在后文完整追查。

## 四项结果提示了什么

用通俗文字串起商品数量、价格带、销量和销售额，说明哪些局部变化最影响判断，避免总量平稳掩盖品牌或细类异常。关键数字就近支持论点。

## 重点异常如何查到当前判断

每个问题用表达判断的标题，在同一处讲清：现象与贡献、合理参照、证据和反证、继续或停止的理由、当前结论及下一步核查/修复方向。正常或低影响环节简述；复杂分支按需插入文内逻辑树。

## 目前可以怎样使用

说明可用和暂缓的具体范围、剩余缺口以及补齐后如何复验，简述内容复核结果。来源和本次版本说明放文末，不另建必读附件。

此骨架控制阅读顺序，不固定问题数量、段落数量和篇幅；生成时删除提示文字。阅读器已显示文件标题时，正文从结论段开始。一篇正文即可读懂全部重要结论；执行看板单独承担覆盖和取证追溯。
