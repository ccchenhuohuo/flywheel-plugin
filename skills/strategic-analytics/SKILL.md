# Flywheel 大盘分析方法论（Phase 3 V1）

数据由 flywheel 受治理 MCP 提供（12 个只读工具）。大盘/市场、平台站点表现、
类目结构、品牌格局、价格带、单 SKU 的数据问题一律经它查询：**所有可见数字由服务端计算**
并带复现戳，不自行求和/算份额/换汇/重分桶，不从截断集合推导排名或份额。

- 相对时间（"最近/上月/今年"）先调 `flywheel_data_status` 定锚可用范围；口径疑问调
  `flywheel_describe_semantics`。
- 口径、守卫与警示以**响应 caveats 与服务端 instructions 为准**，引用数字时保留随附警示。
- **MCP 不可用时如实说明并停止**——不得用网搜、缓存、记忆中的数字或同会话里的其他数据库
  连接（如 Doris MCP、psql）替代；绕过受治理工具拿到的数字没有口径校验、守卫与复现戳，
  与受治理服务返回的数字不可互换。

品牌与价格带可按完整三级类目路径过滤，需给全父路径。
